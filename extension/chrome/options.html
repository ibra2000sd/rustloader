Rustloader Companion

Pair this extension with the Rustloader app running on this computer. In Rustloader, open Settings → Browser Integration and switch the bridge on. Then either pair automatically (click Pair in Rustloader, then the button below within 120 seconds) or copy the pairing token by hand.

Experimental

Everything stays on this computer: the token and any cookies are only ever sent to Rustloader at 127.0.0.1, never to the network. If the test says Rustloader isn't reachable, make sure the app is running and the Browser Integration toggle is on.
