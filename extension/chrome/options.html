Rustloader Companion

Pair this extension with the Rustloader app running on this computer. In Rustloader, open Settings → Browser Integration, switch the bridge on, and copy the pairing token here.

Everything stays on this computer: the token and any cookies are only ever sent to Rustloader at 127.0.0.1, never to the network. If the test says Rustloader isn't reachable, make sure the app is running and the Browser Integration toggle is on.
