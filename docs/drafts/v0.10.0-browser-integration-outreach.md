Hi! 👋 Good news — browser integration you asked about is now real:
**Rustloader v0.10.0** ships Phase 1.

**What you can do now:** right-click any page or link in Chrome →
**"Download with Rustloader"** — the URL *and the page's cookies* go
straight to the running app, so logged-in or age-gated content extracts
correctly without any cookie-file juggling.

**How to try it:**

1. Update to [v0.10.0](https://github.com/ibra2000sd/rustloader/releases)
   and, in the app, switch on **Settings → Browser Integration** — copy the
   pairing token it generates.
2. Grab `rustloader-chrome-extension-v0.10.0.zip` from the release page,
   unzip it, then `chrome://extensions` → **Developer mode** →
   **Load unpacked** → select the unzipped folder.
3. Extension → **Options** → paste the token → **Save** →
   **Test connection**.

A few honest notes: it's **off by default**, listens on `127.0.0.1` only
(nothing leaves your machine), and Phase 1 is Chrome-only with the app
needing to be running. Cookies from the browser apply to extraction; the
download stage still uses the cookies set in Settings — that's next on the
list, along with automatic media detection and Firefox support.

**I'd really like your feedback:** does pairing work first try? Does it
handle the sites you wanted it for? Anything confusing in the setup?
Open an issue with whatever you hit — this is a beta and reports directly
shape Phase 2. Thanks for pushing for this feature! 🙏
