The signature visual: N cells = N parallel segments, each filling independently; saturated cells dim to rust-600, active edges glow (web-only).

```jsx
<SegmentBar segments={[100,100,84,61,90,42,100,77,55,68,100,31,88,49,72,60]} />
<SegmentBar count={16} status="queued" />
```
