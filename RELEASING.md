# Releasing Rustloader

How a release actually ships, split into what CI does on its own and what
the maintainer does by hand. Written for v0.10.0; the process is the same
for later versions (substitute the version).

## What CI does automatically (on tag push)

`.github/workflows/release.yml` triggers on any `v*` tag and publishes a
GitHub release containing:

- `rustloader-linux-x86_64.tar.gz`
- `rustloader-macos-arm64.tar.gz`
- `rustloader-macos-x86_64.tar.gz`
- `rustloader-windows-x86_64.zip`
- `rustloader-chrome-extension-v<version>.zip` (since v0.10.0 — the
  `extension/chrome/` files only, zipped at the archive root so the
  unzipped folder is directly Load-unpacked-able)
- `SHA256SUMS.txt` covering all of the above

These are **bare binaries**, not the macOS `.app` bundle. Hyphenated tags
(`v0.10.0-rc.1`) publish as pre-releases.

## What the maintainer does by hand

### 1. Tag (after the release PR is merged and CI is green)

```sh
git checkout main && git pull
git tag v0.10.0
git push origin v0.10.0
```

Then watch the "Release Build" workflow and verify the release page shows
all six assets listed above.

### 2. macOS `.app` / `.dmg` (manual — CI does not build this)

The self-contained universal (x86_64 + arm64) `Rustloader.app` — bundling
yt-dlp (onedir), ffmpeg/ffprobe, and deno — is built locally on a Mac:

```sh
# needs both rustup targets: x86_64-apple-darwin and aarch64-apple-darwin
./scripts/build-macos-app.sh
```

Output: `dist/Rustloader.app` and `dist/Rustloader-<version>.dmg` (the
script reads the version from `Cargo.toml`). The bundle is unsigned;
signing/notarization steps (Developer ID required) are in
[`SIGNING.md`](SIGNING.md). To attach the dmg to the release:

```sh
gh release upload v0.10.0 dist/Rustloader-0.10.0.dmg
```

Note: `SHA256SUMS.txt` is generated by CI before any manual upload, so a
hand-attached dmg is not covered by it — paste its `shasum -a 256` into the
release notes if you attach one.

> History: no published release up to and including v0.9.0 carried an
> `.app`/`.dmg` asset — v0.9.0 shipped the four CI archives plus
> `SHA256SUMS.txt` only. The `.app` path has always been this manual script
> (added in #55, made universal in #58, launcher fix in #60).

### 3. After the release page is live

- Verify the asset list (six CI assets; plus the dmg if uploaded).
- Download the extension zip, unzip it, and Load-unpacked it once as a
  smoke test.
- Post any planned announcement/outreach comments (drafts live in
  `docs/drafts/`).
